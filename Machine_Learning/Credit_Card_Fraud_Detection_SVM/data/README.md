# Credit Card Fraud Detection

This project focuses on detecting fraudulent credit card transactions using Machine Learning techniques.

---

## Dataset

The dataset used in this project is publicly available on Kaggle:

https://www.kaggle.com/datasets/boiniabhiram/credit-card-fraud-detection

---

## Download Instructions

1. Open the dataset link above.
2. Sign in to your Kaggle account.
3. Download the dataset ZIP file.
4. Extract the ZIP file.
5. Place the `creditcard.csv` file inside:

```text
Machine_Learning/Credit_Card_Fraud_Detection/data/
```

---

## Dataset Information

Contains credit card transactions made by European cardholders in September 2013.
Highly imbalanced dataset:
1. Legitimate transactions → Class 0
2. Fraudulent transactions → Class 1
